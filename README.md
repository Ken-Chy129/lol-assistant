# LOL Assistant

英雄联盟助手工具，通过调用 League Client API（LCU API）实现游戏客户端的自动化操作，支持获取召唤师信息、段位查询、聊天室消息发送等功能。

## 功能特性

- **客户端自动连接**：自动检测并连接本地运行的英雄联盟客户端
- **召唤师信息**：获取当前登录账号的召唤师信息
- **段位查询**：查询召唤师排位赛段位与分数
- **队伍信息**：获取当前对局队伍成员信息
- **聊天功能**：向聊天室发送消息

## 技术栈

- Java 17
- OkHttp / HttpClient（LCU API 调用）
- Fastjson（JSON 解析）

## 工作原理

程序通过读取英雄联盟客户端进程的启动参数，获取 LCU API 的端口和认证令牌，然后通过 HTTPS 请求与客户端进行交互。

## 使用方法

1. 启动英雄联盟客户端并登录
2. 运行本程序，自动检测并连接客户端
3. 通过 API 调用获取所需信息

```bash
mvn clean package
java -jar target/lol-assistant.jar
```

> 需要在英雄联盟客户端运行的情况下使用。
